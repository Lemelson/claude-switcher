# Claude Switcher

Полное описание проекта (переключатель, сборщик расходов и страницы в CodexBar) на английском: [README.md](README.md). Меню живёт в форке [Lemelson/CodexBar](https://github.com/Lemelson/CodexBar).

Переключатель аккаунтов приложения Claude (claude.ai для Mac, вкладка Code тоже) в строке меню.

## Как пользоваться

- Значок с двумя человечками в строке меню → щёлкнуть по аккаунту. Без вопросов: Claude сразу закроется, вход подменится, и Claude откроется уже в выбранном аккаунте (около 5 секунд).
- **Войти в новый аккаунт…** → Claude откроется на экране входа. Войдите, и примерно через 45 секунд переключатель сам спросит, как назвать новый аккаунт.
- **Не нажимайте «Выйти» (Log out) в самом Claude.** Выход отменяет вход на сервере, и сохранённая копия этого аккаунта перестаёт работать. Если это случилось, переключатель заметит выход по журналу Claude, пометит аккаунт «нужно войти заново» и сохранит вход сам, когда вы снова войдёте.
- После любого входа в Claude переключатель через 45 секунд сам обновляет сохранённый вход этого аккаунта.
- **Открыть журнал** → `~/Library/Logs/ClaudeSwitcher/switcher.log`: каждое переключение, сохранение и восстановление (размеры файлов, UUID, без токенов), плюс строки о входе и выходе из журнала Claude (`~/Library/Logs/Claude/main.log`).
- **Спрашивать аккаунт при запуске Claude** (включено): если открыть Claude обычным способом и сохранено два аккаунта или больше, всплывёт окно выбора. Нажатие Enter оставляет текущий аккаунт. Окно появляется только при запуске настоящего Claude: macOS объявляет запуском Claude и программы из его сессий (например, `osascript` с уведомлением), такие события переключатель пропускает и пишет в журнал.
- Если открыть «Claude Switcher» ещё раз (через Spotlight), тоже появится окно выбора аккаунта.
- **Управление** → переименовать или удалить аккаунт, а также **Подключать VPN Happ** для аккаунта (в меню у него пометка «· VPN").
- **VPN Happ.** При переключении на такой аккаунт: Claude закрывается → Happ запускается и подключается (`happ://connect`, сервер — последний выбранный в Happ) → переключатель ждёт, пока маршрут пойдёт через utun, заработает xray и ответит api.anthropic.com → только потом открывается Claude в этом аккаунте. Затем сверяется внешний IP: через VPN он обязан отличаться от прямого (оба пишутся в журнал со страной и провайдером). Если Happ не подключился за ~40 с или IP не сменился, переключение отменяется. При уходе с такого аккаунта: Claude закрывается → `happ://disconnect` → `happ://close` (Happ закрывается полностью) → проверка, что туннеля нет и внешний IP снова прямой → открывается следующий аккаунт. Если Happ не закрылся, следующий аккаунт не открывается.
- **Войти в новый аккаунт через VPN Happ…** → Claude закрывается, Happ подключается с проверкой IP, Claude открывается на экране входа. Обычное «Войти в новый аккаунт…» наоборот закрывает Happ, чтобы новый аккаунт не был связан с IP VPN.
- VPN работает на весь Mac, а не только для Claude: вход идёт через системный браузер (Google), а вкладка Code запускает отдельные процессы, так что VPN только для Claude пропускал бы часть трафика мимо. Если Claude открыли вручную в VPN-аккаунте без подключённого Happ, переключатель закроет Claude, подключит Happ и откроет снова. При сохранении нового аккаунта в окне с именем есть галочка «Подключать VPN Happ» (стоит сама, если Happ подключён).

- **Аккаунты Codex** (второй раздел меню, виден, если на Mac есть хоть один аккаунт Codex): аккаунт из `~/.codex/auth.json` (с галочкой) и аккаунты, которые хранит CodexBar, с вашими именами из `account-names.json` и тарифом. Щелчок делает выбранный аккаунт аккаунтом Codex через `CodexBarCLI codex-accounts promote` и перезапускает T3 Code (если в нём идут задачи, сначала спросит). `ClaudeSwitcher codex-list` показывает найденные аккаунты, `ClaudeSwitcher codex-selftest` проверяет поиск, меню и переключение на ненастоящих файлах.

Без перезапуска Claude сменить аккаунт нельзя: он держит вход в памяти. Поэтому перезапуск делается автоматически.

## Как устроено

Вход хранится в `~/Library/Application Support/Claude`:
`Cookies`, `Local Storage`, `Session Storage`, `IndexedDB` и ключи `oauth:*`, `lastKnownAccountUuid`, `bootSideSessions`, `sshTransportFlagLastAnswer` в `config.json`.
Для каждого аккаунта копия этих файлов лежит в `~/Library/Application Support/ClaudeSwitcher/profiles/<id>/`. Всё остальное общее для всех аккаунтов: настройки, MCP, папки, VM, кэши. Сессии Code Claude сам раскладывает по аккаунтам (`claude-code-sessions/<uuid аккаунта>`).

Перед первым переключением делается резервная копия: `~/Library/Application Support/ClaudeSwitcher/backups/original-*`.

Перед уходом с аккаунта его файлы сохраняются заново, так что обновлённые токены не теряются.

## Сборка

```bash
./build.sh --install
```

Команда ставит приложение в `~/Applications/Claude Switcher.app`. В командной строке есть `ClaudeSwitcher list | add-current <имя> | restore <имя> | set-happ <имя> on|off | happ-test state|connect|shutdown|ip | selftest`. `selftest` гоняет 7 переключений между тремя фальшивыми аккаунтами (два без VPN, один с VPN) с настоящим Happ и проверяет файлы, Happ, туннель и внешний IP; настоящий Claude и профили не трогает.
